Questions from the helicopter.

Does the redactor send my logs anywhere?

No. It is a regular expression pass in JavaScript on this page. There is no upload endpoint. You can load the page, go offline and it still works.

Will it catch everything?

No. It catches well-shaped things: emails, common API key formats, bearer tokens, EVM and Zcash addresses, hex private keys, PEM keys, Luhn-valid card numbers, IPv4 addresses and home-folder usernames in macOS and Linux paths. It does not catch Windows paths, and it will miss names, addresses and anything that looks like ordinary words.

When does the relay take off?

Coming soon. We are building toward direct shielded ZEC payments and a hosted agent relay. For now, take the free redactor for a spin; passes will open when the landing pad is ready.

Do you track me?

This site loads no analytics, no third-party scripts and no web fonts. Our hosting provider still sees ordinary request logs, like every website.
