FAQ and honest limits

Does the redactor send my logs anywhere?

No. It is a regular expression pass in JavaScript on this page. There is no upload endpoint. You can load the page, go offline and it still works.

Will it catch everything?

No. It catches well-shaped things: emails, common API key formats, bearer tokens, EVM and Zcash addresses, hex private keys, PEM keys, Luhn-valid card numbers, IPv4 addresses and home-folder usernames. It will miss names, addresses and anything that looks like ordinary words.

Is the paid privacy relay live?

No. The next prototype will verify direct shielded ZEC payments through a third-party provider. It is not a swap, and it does not make ordinary x402 transfers private. Nothing on this site moves money.

Do you track me?

This site loads no analytics, no third-party scripts and no web fonts. Our hosting provider still sees ordinary request logs, like every website.

Is this a joke?

The helicopter is a joke. Leaking secrets from agent logs is not.
